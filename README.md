 Liberal Arts Department Website

Project Description
This project is a website developed using Flask, HTML, and CSS for the Department of Liberal Arts. 
The website provides information about the department, students, faculty, courses, and placement records.

Features
- Home page with department introduction
- Student list
- Faculty list
- Placement records with images
- Login page
- Navigation between pages

 Technologies Used
- Python (Flask)
- HTML
- CSS
- Jinja Templates

## How to Run the Website

1. Install Flask
pip install flask

2. Run the application
python app.py

3. Open the browser and go to
http://127.0.0.1:5000/
